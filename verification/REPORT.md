# Проверка комплекта / 26 сентября 2026

## Фактически выполнено

**99 Python-тестов пройдены.** Сохранены `python-tests.txt` и `python-tests.junit.xml`.
Проверены команды и сроки действия, строгие JSON Schema, повторные ID, транзакционная выдача
слотов, отказ BUSY без отложенного исполнения, конфликты файлов, запрет опасных путей и symlink,
сбор stdout/stderr, некорректный UTF-8, ограничения размера вывода, timeout/cancel, bootstrap-план,
форматы документов, приватный файл состояния и статический loopback HTTP-сервер.

**44 браузерные проверки пройдены.** Полный перечень: `ui-tests.json`.
Настоящий Chromium исполнил HTML/CSS/JS: навигацию, формы, темы, вкладки результатов, фильтры,
выбор worktree для VS Code, отказ переключения грязной области, чистое переключение ветки,
создание проекта/области, конечные маршруты, отказ BUSY, отмену и отсутствие автоповтора.
Проверены ширины 1280, 1600, 2560 и 390 px, отсутствие горизонтального выхода страницы,
переключение reduced motion. Ошибок JS и внешних сетевых запросов не зарегистрировано.

Браузерный тест загружает тот же автономный HTML через Chromium `set_content`: управляемая
среда блокирует навигацию браузера к локальным file/HTTP URL. Это **не** заявляется как проверка
всех политик file:// на компьютере владельца. Локальный HTTP-сервер отдельно проверен реальными
loopback HTTP-запросами: ожидаемые ответы, Host-проверка, запрет POST и доступа за каталог.
Тестовый Chromium запускается с --no-sandbox только как контейнерный стенд для доверенного UI;
это не настройка будущего исполнителя пользовательских проектов.

**Настоящая Git-демонстрация:** создан новый временный игрушечный репозиторий, две ветки и два
worktree; один вариант прошёл unittest, другой намеренно упал. Снимки зафиксированы до проверки.
Повторные ID не вызвали второго исполнения. Фактические манифесты и потоки сохранены в
`reference-demo/correct/` и `reference-demo/failing/`. Полные временные пути в исходном summary
описывают среду сборки; для архива используй добавленное поле bundled_evidence.

**Drive-план:** `drive-plan.json` описывает 26 создаваемых объектов — папки, native Docs и схемы.
Все 12 рецептов команд строго валидируются, оставаясь DRAFT с нулевым epoch и устаревшими датами.
Bootstrap не запускался с --apply. Файлы и полномочия Google/GitHub пользователя не изменены.

## Что обнаружено и исправлено при проверке

В мобильном макете горизонтальная навигация растягивала страницу; ограничен grid minimum и
добавлен доступный выбор проекта. Разделены маршруты VERIFY/PUBLISH/CREATE_PROJECT; создание
и публикация не выдумывают запуск тестов. VERIFY сохраняет редактируемые файлы и HEAD, а отчёт
привязывает к снимку. Исправлены общий контракт вывода, термин base_head и ссылки на инструкции.
Введён operation-manifest для логов действий, у которых вообще нет программного запуска.

## Что НЕ проверено и НЕ реализовано

Интерактивный UI не подключён к reference-ядру. Production API, watcher, GitHub-адаптер,
контейнерный исполнитель и фоновые cloud workflows ещё не реализованы. Не проверялись реальные
OAuth scopes/редактирование Docs между двумя приложениями, GitHub entitlement для private draft PR,
выдача чату доступа к репозиториям, rootless-изоляция на компьютере владельца и запуск его проектов.
Это обязательные отдельные gates в пакетах Codex, а не подразумеваемый результат текущих тестов.

Здесь не обещается распределённое exactly-once. Исполняемое ядро демонстрирует локальное
дедуплицированное admission; внешние побочные эффекты потребуют журналирования и reconciliation.

## Воспроизведение

```bash
python -m pip install -e '.[test,ui-test]'
python -m pytest -q --junitxml=verification/recheck.junit.xml
CHROMIUM_PATH=/usr/bin/chromium python scripts/test_ui.py
python -m bridge_reference.demo
python scripts/bootstrap_drive.py --plan
```

Версии среды: `environment.json`. Контрольные суммы файлов: `../SHA256SUMS`.
