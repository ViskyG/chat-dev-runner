Two bounded fixes close gaps found in the audit:

1. Keyboard ArrowLeft/ArrowRight/Home/End tab selection now calls `loadTabInspections()` after rendering and restoring focus. Previously a user could enter **Tests** or **Console** with an arrow key and leave JUnit cases or structured ERROR/FATAL events indefinitely at `Читаем…` until clicking the tab. The function is a no-op for Summary/Files; it uses the existing bounded GET-only inspection route and checks selected project/workspace/tab before repainting.
2. When no GitHub repository has local import approval, the disabled `Существующий GitHub` option now has the exact reason in `title` and `aria-description`, plus a visible `disabled-reason` message beside the source selector. It remains enabled when an approved repository exists; no approval policy changed.
