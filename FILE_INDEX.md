# Карта комплекта

Начать с `runner-prototype.html` → `docs/OWNER_GUIDE_RU.md` → `codex/START_HERE.md`.
Для Drive: `drive-seed/README.md`. Проверенные возможности: `verification/REPORT.md`.

| Раздел | Что в нём |
|---|---|
| prototype + runner-prototype.html | интерактивная демонстрация без внешних подключений |
| bridge_reference + tests | исполняемая механика и локальные тесты |
| docs | цели, маршруты, предметная модель, форматы, безопасность, UI, восстановление |
| codex | английские инструкции, 8 пакетов, checkpoints и приёмка |
| drive-seed + bootstrap | инструкции, команды, шаблоны, создание собственного пространства |
| schemas + examples + config | типизированные контракты и инертные примеры |
| deploy | текущий статический прототип и обозначенный шаблон будущего сервиса |
| verification | фактические отчёты, браузерные снимки, локальные доказательства |
