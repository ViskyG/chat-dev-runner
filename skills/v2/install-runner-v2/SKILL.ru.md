# Установка или обновление Runner v2 — предварительный исходник

Полный русский текст `install-runner-v2`, версия `2.0.0-source-preview`.
[English SKILL.md](SKILL.md) — единственная точка выбора; этот файл не отдельный
зарегистрированный скил и не свидетельство установленного v2.

Применять по просьбе установить/обновить этот проект. Прочитать AGENTS, реальные
версию и свидетельства установки, разделы «Owner configuration and service» и
«Upgrade and rollback boundary» в [V2 operations](../../../docs/V2_OPERATIONS.md).

Если запрос включает подключение проекта, выполнить
[процедуру регистрации](../../../docs/PROJECT_ENROLLMENT.md#русский).
Установленная служба или новая runtime-запись сами по себе не завершают регистрацию для чата.

Без раскрытия секретов установить обычную учётную запись, существующую службу,
фактические XDG-пути, `runner_id` в БД, версию схемы, точные Drive root/index,
выбранные GitHub-репозитории и пути установленных инструментов/профилей. Сохранить
одну пользовательскую службу и loopback. GitHub-only не требует Google.
Владелец вправе вручную добавить только нужный репозиторий; требование
«All repositories» недопустимо.

Использовать уже данное разрешение. Для нового существенного изменения
развёртывания подготовить конкретные исходники/конфигурацию/схему/службу и откат;
согласовать только то, что ещё не разрешено. Одобрение разработки исходников не
устанавливает wheel, глобальные скилы или системный SDK. Не переспрашивать
согласованные доверие, каналы и обычную подготовку по разрешённому рецепту.

До схемы 10 остановить службу и выполнить `runner backup --output ...` именно
сохранённым старым бинарником схемы 9. Проверить идентичность и восстановление
копии; сохранить старый бинарник и защищённую конфигурацию. После обновления
полагаться только на проверенный backup, включающий каталоги v2. Старый код не
должен открывать БД схемы 10; восстановление не разрешает повторять старые задачи.

Устанавливать проверенный owner-local `runtime-v2.json` с mode 0600 и совпадающим
`runner_id`, осознанно сохранить `enable_v1`. Секреты остаются вне репозиториев;
существующие Drive root/index не менять. Одобренный wheel и план службы применять
существующим установщиком, не вторым daemon. Настроенный обычный запуск включает
приём; `--start-unarmed` оставляет его выключенным в контрольном процессе.

Если обновление меняет принимаемый контракт команд, обновить безопасные metadata
регистрации/каталога до фактически установленной версии и согласованной
опубликованной ревизии скилла/схемы. Сохранить все привязки получателей, command
tabs, ожидающие намерения и квитанции. Прочитать обновлённый каталог коннектором
чата: одного обновления локального бинарника недостаточно для инструкций нового чата.

Вернуть идентичность исходников/wheel, применённый объём, реальные наблюдения
каналов/backend, проверенный откат и открытые платформенные проверки. Статус
развёртывания повышать только по реальной установленной приёмке. Чтение этих
файлов не регистрирует скил и не разрешает правки канонической библиотеки.

Происхождение: [неизменённый проектный перевод](../../../design/github-native-v2/skills/install-runner/SKILL.ru.md)
и [индекс хешей](../PROVENANCE.json). Для конкретных интерфейсов действуют текущие
исходники, а не историческая формулировка «ещё не реализовано».

При обновлении до dev7 указывайте `relative_inbox: "handoffs"` для новых
передач. Сохраняйте старые пакеты `.runner/handoffs/`, их квитанции и инструкции;
оба каталога защищены от включения в исходники.
